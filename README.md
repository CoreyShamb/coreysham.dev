# CoreySham Developer Portfolio

Personal developer portfolio for Corey Shamburger, showcasing software development projects, technical skills, experience, and professional work.

The portfolio is built with Next.js, React, TypeScript, Tailwind CSS, and shadcn/ui and is deployed through Vercel.

## Live Site

Production: https://coreysham.dev

## Technology Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- shadcn/ui
- pnpm
- Vercel

## Getting Started
